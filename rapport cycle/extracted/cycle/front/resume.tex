{\Large\bfseries Résumé}\par\medskip

\noindent\textbf{Mots-clés :} Agriculture intelligente, YOLOv11, RAG, Darija tunisienne, IoT,
FastAPI, React PWA, architecture multilocataire, CRISP-DM.

\medskip
Ce mémoire présente \textbf{Smart Farm AI Enterprise}, une plateforme d'agriculture
intelligente souveraine conçue pour le contexte tunisien. La plateforme intègre une
architecture microservices FastAPI, une interface React 18 PWA conçue selon une approche \textit{hors connexion d'abord}, un système
de détection visuelle basé sur YOLOv11 (11 catégories, mAP@50 = 84.7\% $\pm$ 1.8\%) et
un agent conversationnel en Darija tunisienne combinant RAG ChromaDB, Ollama
(modèle Labess-7B) et Groq API (Llama-3.3-70B).

Le module avicole intègre cinq modèles d'apprentissage automatique incluant
une régression polynomiale de degré 2 pour la prédiction de l'indice de consommation
($R^2 = 0.891 \pm 0.024$, IC 95\%, 5-fold CV), un classifieur de risque de mortalité (précision
= 87.3\% $\pm$ 2.1\%) et une détection d'anomalies par score-Z.

La validation terrain sur 7 fermes pilotes tunisiennes obtient un score de satisfaction utilisateur
de 4.2/5 et une réduction perçue de 23\% des pertes animales. L'évaluation de l'agent
Darija produit un coefficient Kappa de Cohen de $\kappa = 0.76$ et un score BLEU-4 de 0.68, attestant
d'une qualité de génération linguistique satisfaisante pour un usage professionnel.

{\Large\bfseries Abstract}\par\medskip

\noindent\textbf{Keywords:} Smart Farming, YOLOv11, RAG, Tunisian Darija, IoT, FastAPI,
React PWA, architecture multilocataire, CRISP-DM.

\medskip
This thesis presents \textbf{Smart Farm AI Enterprise}, a sovereign smart farming
platform designed for the Tunisian agricultural context. The platform integrates a
FastAPI microservices backend, an offline-first React 18 PWA, a YOLOv11-based visual
detection system (11 categories, mAP@50 = 84.7\% $\pm$ 1.8\%), and a Tunisian Darija
conversational agent combining ChromaDB RAG, Ollama (Labess-7B) and Groq API
(Llama-3.3-70B).

The poultry ERP module embeds five machine learning models including a degree-2
polynomial regression for Feed Conversion Ratio prediction ($R^2 = 0.891 \pm 0.024$, 95\% CI,
5-fold CV), a mortality risk classifier (accuracy = 87.3\% $\pm$ 2.1\%), and Z-score anomaly
detection.

Field validation across 7 Tunisian pilot farms yields a user satisfaction score of 4.2/5
and a perceived 23\% reduction in animal losses. The Darija agent evaluation achieves
Cohen's Kappa $\kappa = 0.76$ and BLEU-4 = 0.68, demonstrating acceptable linguistic
generation quality for professional use.
